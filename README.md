# 🎮 AI Dodge Game

This is an AI-based dodge game built using Python and Pygame.

## 🧠 Features

* Player controlled by arrow keys
* AI enemies that follow the player
* Increasing difficulty
* Collision detection
* Score system

## 🚀 How to Run

```bash
pip install pygame
python ai_dodge_game.py
```

## 🤖 AI Logic

Enemies use simple tracking AI to follow the player’s position in real-time.
